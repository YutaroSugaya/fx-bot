# Skill: 通貨ペア選定 (symbol selection)

複数通貨ペア対応 (= multi-symbol runtime は実装済) で、**追加候補ペアが現運用に組み込む価値があるか**
を客観的に評価する。`generate_strategy_config.md` の hourly フローからは呼ばれない。
新通貨ペア追加検討時の独立スクリプト or 手動レビューから呼ぶ。

USD/JPY を主戦場とし、ロットを上げ続けるよりペア分散の方が Sharpe 改善に効くという
方針に基づく。

## 入力 (期待するもの)

- 候補ペア (例: EUR/USD, EUR/JPY, GBP/JPY)
- 過去 N 日 (推奨 30+) の **両ペアの 1m bar** (= candles テーブル or GMO klines)
- 既存ペアの直近 paper / backtest 成績 (PF / MDD / Expectancy)

## 評価する 4 軸 (順に確認)

### 1. 相関係数 (重要度: 高)

USD/JPY との **日次リターン相関**:
- 計算: 日次 close 変化率の Pearson 相関 (30 日以上)
- 判定:
  - `|r| < 0.3` → ほぼ独立、**分散効果あり** ✓ (推奨)
  - `0.3 <= |r| < 0.6` → 中相関、分散効果限定
  - `|r| >= 0.6` → 高相関、分散にならない (同方向に大負けする)
- 円ペア同士 (USD/JPY と GBP/JPY) は経験的に 0.7+ → 注意必須
- USD/JPY と EUR/USD は逆相関気味 (USD が共通)

| ペア | USD/JPY との r | 分散効果 |
|---|---|---|
| EUR/USD | -0.3 〜 +0.2 | ✓ 高い |
| EUR/JPY | +0.6 〜 +0.8 | ⚠️ JPY 共通で同方向リスク |
| GBP/JPY | +0.6 〜 +0.8 | ⚠️ 同上 |
| AUD/JPY | +0.5 〜 +0.7 | ⚠️ |

**判定**: `|r| < 0.5` を新規追加の最低条件に。

### 2. 流動性 / スプレッド (重要度: 高)

GMO 提示スプレッドの **平均値 + 変動係数**:

| ペア | 平常 spread | 平常時 vs USD/JPY 比 | 推奨 |
|---|---|---|---|
| USD/JPY | 0.2 銭 | 1.0× (基準) | — |
| EUR/USD | 0.4 pips ≒ ¥0.06 (105円換算) | やや高い | △ |
| EUR/JPY | 0.5 銭 | 2.5× | ⚠️ コスト高 |
| GBP/JPY | 1.0 銭 | 5.0× | ❌ コスト過大 |

**判定基準**:
- スプレッドが USD/JPY の **2 倍以下**なら追加候補
- 2 倍超なら TP/SL レンジを USD/JPY の 2 倍に広げる必要 (= 1 日の trade 機会が減る)
- 5 倍超 (GBP/JPY 等) は単独で edge が無いと不可

### 3. 時間帯別の挙動 (重要度: 中)

JST ごとの「スプレッド倍率 (vs 24h 平均)」と「実現ボラ」のマトリックス:

| 時間帯 | USD/JPY | EUR/USD | EUR/JPY | 推奨運用時間 |
|---|---|---|---|---|
| 東京 08:30-15:00 | spread 1.0× / vol 中 | spread 1.5× / vol 低 | spread 1.2× / vol 中 | USD/JPY ◎, EUR系 △ |
| ロンドン 16:00-22:00 | spread 1.0× / vol 高 | spread 1.0× / vol 高 | spread 1.0× / vol 高 | 全ペア ◎ |
| NY 22:00-04:00 | spread 1.0× / vol 高 | spread 1.0× / vol 高 | spread 1.0× / vol 高 | 全ペア ◎ |
| 早朝 04:00-08:00 | spread 2.0× / vol 低 | spread 2.0× / vol 低 | spread 3.0× / vol 低 | 全ペア × |

**判定**: ペア追加時は `bot_config.scheduler.start_time` / `end_time` も再評価。
EUR/USD なら東京時間を `no_trade` に、ロンドン時間中心に。

### 4. 既存ペアとの 「同時に負ける」リスク (重要度: 高)

過去 90 日の **同日 PnL 相関**:
- USD/JPY が大負けした日 (PnL < -3σ) に候補ペアも負けたか?
- もし両方マイナスが 70% 以上の日に重なる → account-wide MDD が 2 倍化

判定: 「同日 -3σ 重複率 < 50%」を必須条件に。

## 通貨ペア追加ゲート

新規追加するには **全 4 項目クリア**:
- [ ] 追加ペア単体の Backtest PF > 1.3
- [ ] 追加ペア単体の Paper PF > 1.2
- [ ] 既存ペアとの相関 |r| < 0.5
- [ ] account-wide MDD が許容範囲 (口座資金比 15% 以内)

## 推奨追加順

1. **USD/JPY** (主戦場)
2. **EUR/USD** (JPY 換算ロジックの検証用、最初は Paper のみ)
   - 利点: USD/JPY と低相関、流動性最高、欧州時間中心の運用
   - 注意: PnL が USD 建て → JPY 換算ロジックが必要 (`adapter/broker` 拡張)
3. **EUR/JPY** or **GBP/JPY** (JPY ペア追加)
   - 利点: 既存の JPY 換算をそのまま使える
   - 注意: USD/JPY との高相関 → account-wide JPY exposure cap 必須
4. **AUD/JPY** (リスクオン/オフ感度を取りに行く)

## 出力フォーマット (markdown)

```markdown
## 候補ペア: <PAIR>

### 1. 相関 (vs USD/JPY)
- r = <値>, 期間 <from> 〜 <to>
- 評価: <分散効果あり / 限定的 / 同方向リスク>

### 2. スプレッド
- 平常時平均: <値> pips (USD/JPY 比 <ratio>×)
- 評価: <推奨 / 注意 / 不可>

### 3. 時間帯
- 推奨運用時間: <list>
- 非推奨時間: <list>

### 4. 同時に負けるリスク
- USD/JPY 大負け日の重複率: <%>

### 結論
- 追加判断: ✓ 候補 / △ 保留 / ✗ 不可
- 理由 (3 行以内)
- 次の検証ステップ: <Paper N 週間 / Backtest PF 確認 等>
```

## アンチパターン

- ❌ 相関 r だけ見てスプレッドを無視 → 1 trade あたりコスト過大で edge 消える
- ❌ 「USD/JPY 1 ペアに集中するのはリスクだから」だけの感情論で追加 → 同方向リスクに気付かない
- ❌ 過去 1 ヶ月の backtest だけで判断 → サンプル不足、季節性ある
- ❌ ペア追加と同月にロット拡大もする → 変数増やしすぎて原因分析不能
